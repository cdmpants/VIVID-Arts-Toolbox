Export to Painter (file-driven)
- Copies VIVID_Arts.spp next to the .blend (named after *_Optimized mesh)
- Writes vivid_painter_config.json with resolution, Is Surface, export dir, texture paths
- Optionally launches Painter with the project + mesh
- Actual SPP wiring happens in Painter via the VIVID_Configure_From_JSON.py plugin/script
